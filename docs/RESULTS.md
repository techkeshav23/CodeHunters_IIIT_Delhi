## 6. The model on held-out situations

The 340 rows hold only 66 distinct messages: 22 situations, each written in English, Hinglish and Hindi (other rows repeat a message with a different location). A random row split would put the same message, or its translation, on both sides and score the model on text it was trained on, so `scripts/train_triage.py` splits by situation, all three languages together.

- Test: 6 situations, one per class, seed 13: `em_chest`, `fu_hello`, `gp_second`, `lab_sugar`, `nu_im`, `pm_weak`. Not used for any choice.
- Validation: leave-one-situation-out on the other 16; it picked C = 0.5 and rules weight 0.4.
- The deployed model was then refit on all 22 situations with those settings.

"Model + rules" is what the API does: red-flag rules first, then a model emergency above its threshold, then the blend of model and rules. "Model alone" is the model's top class with no rules.
